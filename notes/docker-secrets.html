ENGINEERING NOTE / 3 MIN READ

Docker secrets, explained

Give each container access to the password files it needs.

Separate passwords from configuration

The Inception Compose file keeps runtime settings in an environment file and grants password files as secrets. MariaDB gets its database passwords; WordPress gets its application and database passwords.

Define, then grant

secrets:
  db_password:
    file: ../secrets/db_password.txt

services:
  mariadb:
    secrets:
      - db_password

Compose mounts the granted file at /run/secrets/db_password. The service’s startup code reads that file when preparing the database.

Know the boundary

Local Compose secrets use file mounts. They reduce the need to pass passwords as environment variables, but they do not automatically encrypt the source files on the host. Keep those files out of version control and restrict access to them.

Read the source

Inspect the project’s Compose configuration and the Docker Compose secrets documentation.
