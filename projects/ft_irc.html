PROJECT STUDY / NETWORKING

ft_irc

A multi-client IRC server with authentication, channels, messaging, operator commands and buffered nonblocking socket I/O.

C++98 · Sockets · Nonblocking I/O

Repository ↗

The problem

Support multiple IRC clients without assuming that a socket read contains a whole message or that a write sends the entire response.

A design decision

Keep input and output buffers per client. Accumulate received bytes until a CRLF-delimited line is available; consume only the number of bytes actually sent and use POLLOUT while output remains.

A debugging edge case

Network reads and writes can be partial. The client preserves incomplete input across reads, and the server handles EAGAIN/EWOULDBLOCK without disconnecting a client.

A possible next iteration

A useful next iteration would add integration tests for fragmented commands, slow readers and disconnects during a channel broadcast.
