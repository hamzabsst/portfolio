PROJECT STUDY / GRAPHICS

cub3D

Render a textured first-person scene from a grid map using raycasting and DDA traversal.

C · Raycasting · MiniLibX

Repository ↗

The problem

Convert a two-dimensional map into a first-person view with consistent wall distances and texture coordinates.

A design decision

Use DDA to step across grid boundaries until a ray hits a wall. Compute a distance from the hit axis, then use the hit position to select a texture coordinate.

A debugging edge case

Maps can have rows of different lengths. The raycaster checks both map boundaries and the current row length before reading a cell, and treats spaces as a boundary.

A possible next iteration

A useful next iteration would introduce a rendering abstraction before a WebAssembly port, separating the raycasting core from MiniLibX window and input APIs.

Explore the implementation

This study describes the source at commit 36612f3. The edge case is a code walkthrough, not a personal debugging story.
