# Hamza Boussetta — Portfolio

Live website: https://hamzabsst.vercel.app/

A static portfolio built with HTML, CSS, and JavaScript.

## Editing

- `index.html`: structure and page text
- `styles.css`: styling
- `script.js`: interactions and character animation
- `content.js`: email, resume link, and project descriptions
- `assets/`: character image and resume PDF

## Local preview

Run `python3 -m http.server 8765` from this folder and open http://localhost:8765/.

## Vercel

Use the Other framework preset, no build command, and the repository root as the output directory. The current live deployment was uploaded directly; automatic deployment requires connecting this repository in Vercel.
